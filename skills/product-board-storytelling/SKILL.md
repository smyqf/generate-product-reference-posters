# 产品展板叙事排版

把展板作为一段可扫读的设计论证：**先被产品吸引，再理解设计依据，最后看见细节与使用价值。** 本技能从用户的产品展板样本提炼构图关系，而非复制某一张海洋、黑底或橙色展板。

## 先明确材料的角色

将输入分为「风格参考」「产品几何参考」「已确认设计内容」三类。参考展板负责构图节奏、色彩组织与信息密度；产品照片或模型负责造型与材质；研究、数据、功能和结构必须来自用户材料或可核验来源。

需要沿用这位用户既有风格时，查看技能随附的 个人展板参考（随原技能附带的 assets/style-reference.jpg；本单文件未嵌入该图片），其中保留了深色、浅色与暖色作品。用户提供新的风格参考时，以本次要求为准；此图只约束视觉语言，不约束新产品外形。

先查看原图。抽取一份产品一致性清单：整体轮廓、部件数量与位置、开孔、接缝、网格、屏幕、材质和指示灯。每张衍生图均用该清单检查。风格参考不可被解释成新产品的外形。

涉及产品图像的选取、裁切、合成或生成时，先读 [product-consistency.md](#product-consistency)，建立本次产品的可追溯特征清单，并按资料充分程度选择制作方法。排版调整不得通过非等比拉伸、镜像或随意改变产品结构实现。用户明确要求的设计变更单独记录，其余特征继续保留。

缺少内部结构、尺寸、实验或研究资料时，先完成外观、细节、CMF、设计意图与场景等已有材料支持的模块。新增功能流程必须标为「概念流程」，内部结构想象必须标为「概念示意」，不冒充验证结果；无法明确表达其不确定性的模块应省略。

## 排版的核心判断

- 用一张显著大于其他图的主视觉确立产品和场景；主视觉可在上部，也可跨栏或成为贯穿版面的构图轴。
- 用隐形的 6 列或 12 列网格组织高密度小模块，图文共享对齐线与间距。大图允许跨栏、出界或切角，小图和正文保持秩序。
- 将内容聚成少量主题区：设计背景／意图、形态与CMF、关键细节、功能或使用流程、应用场景。主题区内可密集，主题区之间保留呼吸区。
- 从产品材质、指示灯或使用环境提炼一个主强调色。深黑、暖米色、森林色、海洋色均按题材选择；单一强调色负责导航和关系，真实材质颜色不被强行统一。
- 用横向色条、短竖线、细分隔和编号构成导读节奏。避免每个模块都加同样醒目的边框。
- 标题层级为产品名／核心价值句／模块名／说明。中文承担准确表达，英文承担对应的专业术语；不得把不同模块机械重复写成 PRELIMINARY RESEARCH。
- 下部用一张细节大图、实际支持的使用流程或应用场景收束，让观看者从分析回到产品。

具体网格、可调比例、深浅色分支与排版检查见 [layout-grammar.md](#layout-grammar)。需要生成或衍生图像时再读 [render-prompts.md](#render-prompts)。其中比例是对样本的视觉估计，用作起点而非测量结论。

## 执行工作流

1. **建立内容地图。** 用现有材料填写每个模块的主旨、图像、文字与证据来源。优先保留能解释产品的内容，不能用虚假调研、性能数字、图表、伪三视图或伪爆炸图填满版面。
2. **确定视觉系统。** 选择展板尺寸、深浅基底、主题色、字体、统一边距和网格；按内容安排视觉重心。尺寸未知时可先做可调整的竖版样稿，说明假设。
3. **先定版面再生成资产。** 确定主图占位、产品朝向、裁切和文字留白，先复用原图、裁切或已有模型渲染；确需生成时，再制作适配位置的产品场景图／细节图。先验证一张关键图，通过后才扩展其他资产；所有生成均继续引用原始产品依据，不能仅引用上一张生成图。图像资产与文字层分开，避免整张生图承担精确排版。
4. **组合成可编辑展板。** 中文、标题、编号、引线、CMF色卡和图解用 SVG、HTML 或用户指定的原生排版工具后排。仅使用通过一致性检查的产品资产，或明确标明且不承担准确外观证明的概念图；核对内容后再渲染预览；保留可编辑源文件及独立图像资产。
5. **实际查看成品。** 全板缩略检查主次与视觉路径，100%查看正文、产品局部、引线与切图。修正溢出、低对比、错字、重复模块、变形产品与过于密集的无效小字；交付源文件及清晰预览，按请求提供PDF或印刷规格。

## 图像工具与组合方式

需要照片、材质、场景或产品衍生图时使用当前可调用的图像生成工具；内置 imagegen 可用时，先读取其技能说明并遵守参考图机制。图标、线框布局、精确文字和简洁流程图优先原生矢量绘制。

用户指定 Nano Banana 等模型时，先发现可调用的模型查询／图像工具并核实精确模型、引用图能力与连接状态；若使用 Weave，先查询 `find_model` 等实际可用工具并遵循返回的计费和授权流程。**需要按次付费或报价批准时，每次先展示具体模型、数量和费用并取得该工具要求的结构化批准。** 未连接、无权限或无该模型时如实说明，使用已获授权且可调用的替代工具，不能声称已用指定模型。本技能不保存某个账户或连接的当前状态。

本技能负责内容与排版策略，可按任务组合 imagegen、PDF、演示文稿等现有技能；不依赖名称不明的「展板出图技能」，不假称发现或调用了不存在的技能。

## 交付与复用

交付中区分原始参考、AI衍生图、人工后排文字与概念示意，简要说明实际使用的生成工具和产品一致性检查结果。记录采用的原始参考、已检查特征、未能核实的视面和替换／修复情况；未实际查看的图像不能写成已通过。不要把预览像素尺寸直接等同于可印刷精度。

后续调用示例：

> 请用 $product-board-storytelling，为这款产品做一张竖版展板。图A是造型参考，图B是我的风格参考；保留部件和材质，采用适合产品的主题色，中文可编辑，已有资料之外的功能仅作概念说明，并交付源文件与预览。

## 附录：产品一致性规则

# 产品一致性：依据、制作与验收

## 建立当前产品的依据

先实际查看原始产品图或模型渲染，标明产品型号、版本与参考编号。多产品、多版本不能混成同一组依据；有冲突时按用户指定版本处理，无法确定且会改变造型时只询问这个必要问题，其余工作继续。风格参考只提供视觉语言。随附案例不能建立当前产品的事实。

为当前任务保留简短特征表，可放在工作笔记中，无需让用户逐项填写：

|特征|原始依据与可见区域|保留要求|核实状态|
|---|---|---|---|
|整体轮廓与主比例|参考编号、视角|长宽高的视觉关系、转折、负空间|可见／有尺寸／未知|
|部件数量和相邻关系|参考编号、部位|按键、开孔、支撑、屏幕等的位置、方向、相对大小|已见／遮挡|
|材质分区与颜色|参考编号、部位|壳体、金属、透明件的分界及固有颜色|明确／受灯光影响|
|识别细节|参考编号、部位|接缝、网格、标识、灯位或其他关键特征|明确／像素不足|

只记录实际存在且影响识别的特征，不必为每个产品套用所有项目。观察比例可作为同视角比较依据，不能从透视照片直接声称准确工程尺寸。左右以产品自身方向为准；不确定时用“参考图画面左侧”。遮挡不等于零件消失，无法看清不能自行补成确定结构。

用户要求改色或改某个部件时，把这项列为“授权变更”；其他特征继续锁定。不要把保持一致性变成拒绝用户明确要求的重设计。

## 先选损失最小的制作方式

- 已有图片足以表达时直接复用；细节优先裁切清晰原图。裁切不能补回原图没有的精度。
- 改版面时先移动图框、等比缩放、调整背景或留白，不横向压扁、纵向拉长或镜像产品；镜像可能交换接口、文字和操作方向。
- 需要准确的新视角、工程细节或多视图时，优先使用对应模型渲染或用户已有的真实多角度图。单张图无法验证背面；确需准确背面时索取必要参考，并继续已知视面的排版。
- 只需换环境时，优先保留原产品像素并制作背景或合成，统一接触阴影、透视与光照。若工具无法保留主体像素，应按生成资产重新检查，不能声称“完全没改产品”。具体编辑遵循实际可用工具的规则。
- 必须生成产品衍生图时采用原图相近视角，明确允许变化的范围。没有隐藏面依据时，不用大角度旋转或虚构爆炸图填版；可改用原视角、可见细节或独立的概念图解。

## 生成时减少累积偏差

先用原始依据制作一张主视觉并验收，再扩展场景或局部。后续每张都引用原始产品图／模型依据；通过验收的主视觉可以补充光照和材质风格，不能替代原始几何依据。避免连续把上一代生成图当作唯一参考。

每张图明确：原始参考编号、要保留的识别特征、允许的变化、镜头与画幅、不能核实的部位。数量要求只针对实际可见或有资料确认的部件，不强迫被遮挡部件全部露出。不要通过加入“精确一致”等形容词代替可核对特征。

需要多张图时记录各自用途和同一产品版本。CMF 色卡对应固有材料颜色，不直接把环境反光当成另一个配色。准确标志或文字优先使用已有合法素材或可编辑文字层；贴放需尊重产品表面透视，不能让后排文字掩盖结构错误。

## 每张图先验收，再进入展板

实际查看原始参考、候选图和必要的局部放大；最终还要查看展板中的实际裁切。相近视角可将主体等比缩放后并排比较；不同视角不能直接用外接框宽高比或像素差判定变形。

按以下顺序检查：

1. 产品身份：轮廓、主比例、部件拓扑与负空间是否改变。
2. 关键部件：数量、相邻关系、方向、连接、开孔与屏幕位置；对遮挡作合理区分。
3. 材质细节：分区、透明度、网格与接缝走向、灯位、固有颜色；区分光照变化与改材质。
4. 场景可信度：产品与地面／手部的接触、尺度、透视、影子；人体或道具是否遮住需要说明的功能。
5. 排版后的结果：是否非等比变形、误镜像、裁掉关键部件，或引线指向错误区域。

用“通过／需修复／无法核实”记录各项结果；只有已核对的可见特征可以记为通过。漂亮的光照不能抵消部件错误，不以整体相似度百分数伪装几何验证。

## 修复与停止条件

- 局部问题：在工具支持时只编辑错误区域，说明应恢复的部件和原始依据；保护其余区域，完成后复查整张图，防止修好一处又改坏另一处。
- 整体轮廓、主比例或部件布局错误：回到原始依据重新制作，或换回原图／模型渲染，不在错误图上反复添加细节。
- 同一资产默认最多两轮针对性修复；没有改善时转用原图、可靠裁切、模型渲染或调整版面。用户明确要求继续尝试时再继续，不自动无限生成；付费工具仍遵循实际授权要求。
- 不可核实的隐藏面：优先换成有依据的视角；仅在用户需要概念表达时保留并明确标记推定。这样的图不能承担准确结构、三视图或产品外观一致性的证明。

交付简要说明哪些图来自原图／模型、哪些为生成衍生、核对了什么，以及尚未验证的部分。若仍有影响产品身份的错误且无可靠替代，不标为成品通过，保留已完成部分并指出所缺依据。

# 展板视觉语法

## 从样本中提炼的逻辑

用户的作品跨越车舱、林下机器人、消费电子和竹林作业产品，存在深色与浅色两种系统。共同点是「大图建立识别 → 紧凑证据解释设计 → 局部或场景再次强化质感」。不能把某个题材的黑底、橙色、车辆或科幻灯效当作所有产品的模板。

| 样本习惯 | 可复用规则 | 排版意义 |
| --- | --- | --- |
| 上部或跨栏大图、环境铺底 | 每板指定一个主视觉，其尺度显著领先 | 远看能识别产品与主题 |
| 调研、CMF、线稿、功能图等小块密集并列 | 小模块按主题聚类并沿共同边界排列 | 近看能理解设计过程 |
| 大幅局部、斜切或跨越模块的产品图 | 以一至两处跨栏打破均分；让小模块承接其边线 | 建立节奏和产品张力 |
| 黑底橙／红／青与浅米色橙并存 | 由产品、灯色和环境决定基底与强调色 | 保留个人语法，适应新题材 |
| 双语模块标题、短条、编号、横向色线 | 为模块使用具体术语；短色条建立导航 | 提高信息密度后的可扫读性 |
| 下部细节、服务流程或实际场景 | 从论证回到产品或使用价值 | 形成视觉收束 |

这里描述的是图像中可观察的结构；不能从缩略参考断言全部字体、尺寸或精确百分比。

## 可调整的起点

以下数值均为**基于样本的视觉估计和实现建议**，并非对参考图的精确测量。用户的实际展板尺寸、内容量和观看距离优先。

| 项目 | 建议起点 | 调整条件 |
| --- | --- | --- |
| 竖版比例 | 接近A系纸张或用户既有版式 | 展会尺寸、并排多板、作品集页面优先 |
| 网格 | 6列起步；细密混合模块可用12列 | 网格是对齐工具，不要求每个模块等宽 |
| 外边距 | 宽度的2%–4% | 出血主图可越界，正文仍遵循安全边距 |
| 栏间距 | 宽度的1%–2% | 缩小后应仍能区分主题区 |
| 主视觉区域 | 板面积约30%–45%，可跨区 | 产品复杂或内容少时扩大；证据丰富时适度缩小 |
| 解释／证据区域 | 约40%–55% | 数据或结构不足时减少模块，不造内容凑比例 |
| 下部收束区域 | 约10%–20% | 可能与证据区共用大细节图或场景图 |
| 独立主题区 | 通常4–7个 | 每区只解决一个主要问题；无材料支持则合并 |

面积区间可能因跨栏或叠层而重叠，不应当作必须加至100%的固定模板。

## 先选叙事，再选布局

**场景主导型：** 主视觉把产品放进真实或明确为概念的环境，上方配置产品名与价值句，下方以问题、CMF、细节、流程解释。适合有明确使用环境的工业产品。

**形态主导型：** 单体产品成为最大的版面形体，模块沿其周围或一侧排列；中下部用可证实的外观细节、形态推演与配色展开。适合消费电子或形态表达强的产品。

**过程主导型：** 保留一个清晰的大产品图，其他区按步骤串联。服务和流程复杂时可扩大过程部分，但流程必须来自现有设计材料，不能凭产品外观推定操作事实。

这些是可组合的构图选择，不是要求每次产出三种方案。

## 配色与材质

深色基底适合金属、深灰机壳、灯光轮廓或低照度环境，可选近黑或带题材色的深灰；浅色基底适合服务、柔和家居、人群场景或竹木材料，使用米白、暖灰等降低纯白的空洞感。

强调色通常只有一个主色：从产品灯色、关键材质或环境提炼，用于模块线、编号、少量标题和关系引导。CMF中的真实产品颜色仍需如实显示。确有屏幕和灯色等第二色时，限制其面积和职责，不使两色争夺主视觉。

避免用大面积霓虹、过度发光和额外装饰制造不存在的工业质感。用户作品的质感主要来自产品曲面、接缝、材质微纹理、灯光边界与尺度关系。

只呈现已有内容支持的标题。例如没有真实调研就不用「用户调研」，没有确认结构就不用「结构爆炸图」。英文不可作为装饰任意重复，中文不可变成看不清的纹理。

每个小模块用短标题、图片和一至三句说明；长段落改为层级清晰的小句。图文围绕同一个结论配对，标注引线应明确落在对应部件。

## 单张图像产品的处理

从一张产品图出发时，可靠内容是整体外观、图中可见部件、材质、CMF与设计意图。可裁切原图获得细节；可用AI构造一致的场景图，但要核对部件数量和轮廓。新的视角是AI衍生概念表达，不能替代模型生成的精确三视图。

产品原图含有界面读数时，只能将其作为原渲染的一部分；未经资料确认，不将读数转写成真实性能。不要从外观猜出滤膜孔径、功率、收集效率、水泵、发电、传感器规格或内部传动。

## 验收顺序

1. 以全板缩略图检查：第一眼看到产品，第二眼看到名称与价值句，第三眼能分辨主题区。
2. 以100%尺寸检查：文本和引线无重叠、图片清晰、部件一致、没有AI文字残留或显著伪结构。
3. 核对每个图表和功能说明的资料依据；概念材料有明确文字标识。
4. 检查中文与英文对应、模块标题不重复滥用、色条与网格有共同秩序。
5. 印刷请求按实际物理尺寸计算栅格图有效PPI；不足时说明限制并调整输出，不只写一个DPI元数据。

# 产品图像提示词与一致性检查

图像制作与验收遵循 [product-consistency.md](#product-consistency)。以下模板中的特征必须从当前产品参考中填写，不能直接沿用案例部件。

## 两类参考必须分开

**Geometry reference／产品几何参考**：只用该产品的原图、实物照片或模型截图控制轮廓、部件、材质、比例、开孔与灯色。

**Style reference／展板风格参考**：只提炼画面重心、镜头、光影、色彩组织、背景气氛与信息密度。不能把风格参考中的车轮、舱门、植物或装饰移植到新产品。

先描述拟放置的版面槽位，例如「横幅主图，产品靠右，左上留空给标题」。同一产品的主图、局部和场景用共同的材质、色温、部件描述，禁止每次随意重设计。

### OCA 外观与信息层的排版建议

采用深蓝基底与青色导读线，保留产品原有橙色指示灯作为少量暖色。原图或一致性通过的主视觉占大面积；以原图裁切补充屏幕、网格、连接和灯光细节。后排可见部件名称、CMF和设计意图。
